# Design philosophy

Buntpapier offers a complete, consistent user and developer experience for Vue SPAs. Components work together around reactive application state, predictable interaction, shared appearance and library-owned validation.

Buntpapier is an application UI system, not an enhancement layer for MPAs or a collection of decorated native inputs. Native elements and browser features are implementation tools where they serve the intended experience. Matching every native behavior is not a goal. Accessibility is part of the component contract, including semantics, keyboard interaction, focus and feedback.
