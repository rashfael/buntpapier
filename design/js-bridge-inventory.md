# JavaScript bridge inventory

Audited against `3.0.0-alpha.18`. The colour derivation has mostly moved to CSS. The remaining bridges handle keyword dispatch, contrast correction, geometry and observation. This inventory records retirement decisions; implementation remains planned where noted below.

Support below comes from the linked platform documentation. Baseline describes current browser releases; it does not prove support at our minimum versions (Chrome 147, Firefox 147, Safari 26). Removal requires checks at those versions and regression tests in all three engines. No new browser experiment ran for this inventory. The observer spike found working inheritance and stylesheet-declared transitions in Chromium 147 and Firefox 148, but missed unset values and hidden-subtree changes. Public-token registration changes fallback semantics; observer adoption remains undecided, with WebKit and integration behavior unverified.

## Decisions

“Retire” means schedule removal with the stated replacement and checks. “Retire when Baseline” also requires the feature at our browser floor. “Keep” means the current contract still needs the code; any narrower exit condition is recorded in the row.

## Outline decision

The SVG helper implements the [floating-label appearance](appearance.md#label-appearance). It observes the rendered label span to size the notch, builds paths from control dimensions and joins the select outline to its popup.

A replacement must preserve the floating label and joined select outline. Verify empty, long and translated labels, custom and late-loading fonts, compact/inline layouts, all shapes, 200%/400% zoom, logical layout, forced colours and select opening above/below. Border segments must work on translucent or patterned backgrounds; decorative notches must not introduce group semantics.

## Code that stays JavaScript

Date parsing, segmented editing, calendar generation, selection, validation, focus management, async button state and Vue model/events implement behavior. CSS does not replace them. Native popovers reduce overlay plumbing but still need synchronization with Vue and the accessibility contract.

`getIconClass()` maps the behavioral `icon` prop to the current icon provider. `resize-observer.ts` delivers resize callbacks and remains needed by the outline today; retain the directive's public contract independently of internal callers. `use-mobile.ts` has no callers in `src` in this audit. Pure presentation should use a media query; changing interaction based on pointer capabilities can still require `matchMedia()`.

The observer does not disappear merely because `if()` ships. Checkbox icon lookup and accent contrast still read CSS, and `deriveDarkVariant()` keeps part of the colour utility code alive independently of observation. Recheck actual imports and public exports before removing any helper or dependency.
